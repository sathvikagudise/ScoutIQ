ScoutIQ — Manual End-to-End Test Queries
========================================

How to use
----------
1. Start the backend:  cd backend && ../.venv/Scripts/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
   (or start from the repo root: .venv/Scripts/python -m uvicorn app.main:app --app-dir backend ...).
2. Create a run in the UI (frontend: npm run dev) or via the API.
3. Copy-paste a batch of queries below into the run, set a target lead count, execute.
4. Open the results page and check: qualification funnel, candidate classification
   (company-qualified / near-qualified / other), leads, contacts, and criteria chips.

What to expect
--------------
Results depend on the web evidence currently available and on source
accessibility (bot-friendly sites research cleanly; 403/5xx sources are
skipped). Exact outputs vary between runs, and a healthy run may legitimately
finish with ZERO qualified leads — very few real companies sit in the $1M-$5M
USD range, run a tech platform, and have minimal/no US presence. When a run
produces zero qualified leads, the funnel and the per-candidate criteria
analysis explain exactly why each company landed where it did. ScoutIQ never
fabricates a missing value: blank CEO names/emails stay blank, funding uses
only evidence-backed figures, and companies that were evaluated always appear
(even in the "other" bucket).

Regex hint for the extraction engine: figures need an explicit magnitude unit
(K/M/B) or "million" plus a $ / USD marker to be considered for the $1M-$5M
financial criterion ("$2 million", "USD 3M", "$2,000,000-ish"). A bare "2M"
without a currency marker is ignored.
